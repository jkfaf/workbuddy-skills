# 鸿-代理 (h-agent)

## 概述

根据湖北诚明律师事务所的标准模板，自动生成三份代理材料：
1. **委托代理合同** — 律师事务所与委托人之间的委托代理��同
2. **授权委托书** — 委托人授权律师代理诉讼的法律文书
3. **律师事务所函** — 律师事务所向法院提交的指派律师函

## 使用场景

当用户说以下内容时触发：
- "鸿-代理"
- "生成代理材料" / "撰写代理材料" / "制作代理材料"
- "我要立案材料" / "帮我做代理合同"
- 用户提供了案件信息并要求生成对应材料

## 工作流程

### 第一步：收集案件信息

| 字段 | 说明 | 用于 |
|------|------|------|
| 委托人名称 | 甲方/委托人全称 | 合同、授权、所函 |
| 委托人地址 | 委托人通讯地址 | 合同 |
| 委托人电话 | 委托人联系电话 | 合同 |
| 对方当事人 | 对方当事人全称 | 合同、授权 |
| 案由 | 纠纷类型 | 合同、授权、所函 |
| 代理阶段 | 一审/二审/再审/执行等 | 合同、授权、所函 |
| 受理法院 | 全称 | 所函 |
| 代理律师 | 律师姓名（多人用顿号分隔） | 合同、授权、所函 |
| 律师电话 | 各律师联系电话 | 授权 |
| 各律师代理权限 | 特别授权/一般授权 | 授权 |
| 文号年份 | 如"2025" | 合同、所函 |
| 律师费金额 | 大写和小写 | 合同 |
| 付款期限 | 几天内付清 | 合同 |
| 输出目录 | 生成文件存放路径 | 输出 |

### 第二步：确认信息

向用户确认所有信息是否正确。

### 第三步：生成材料

调用 `scripts/generate.py` 生成三份 .docx 文件。

## 执行

```bash
cd /root/.codebuddy/skills/h-agent/h-agent && npm install docx --save 2>/dev/null
python3 scripts/generate.py <输出目录> '<JSON>'
```

JSON 格式：
```json
{
  "year": "2025",
  "client_name": "委托人名称",
  "client_address": "委托人地址",
  "client_phone": "委托人电话",
  "opponent": "对方当事人",
  "case_type": "租赁合同纠纷",
  "stage": "一审",
  "court": "武汉市江岸区人民法院",
  "lawyers": "闵寿池、李鸿",
  "lawyer_phones": ["13349921982", "15927260627"],
  "lawyer_authorities": ["特别授权", "一般授权"],
  "fee_cn": "元整",
  "payment_days": "5"
}
```

## 注意事项

- 律所信息（名称、地址、电话、银行账户）为固定内容，不应修改
- 如果用户信息不完整，主动询问缺失字段
- 生成后向用户报告文件路径
