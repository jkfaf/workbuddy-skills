## 常用图床配置

### 1. GitHub 图床

**适用场景**：个人博客、访问量不大的文章

**配置参数**：
```
Repo: username/repo-name
Token: ghp_xxxxxxxxxxxxxxxxxxxx
```

**配置步骤**：
1. 创建 GitHub 仓库（建议 public）
2. 生成 Personal Access Token（需 repo 权限）
3. 在编辑器中填入 Repo 和 Token

**优点**：完全免费、稳定可靠
**缺点**：国内访问可能较慢

---

### 2. 阿里云 OSS

**适用场景**：企业级应用、高访问量

**配置参数**：
```
AccessKey ID: LTAIxxxxxxxx
AccessKey Secret: xxxxxxxxxxxxxxxx
Bucket: your-bucket-name
Region: oss-cn-hangzhou
```

**配置步骤**：
1. 开通阿里云 OSS 服务
2. 创建 Bucket（建议公共读）
3. 创建 AccessKey
4. 在编辑器中填入配置

**优点**：速度快、稳定、CDN 加速
**缺点**：需要付费

---

### 3. 腾讯云 COS

**适用场景**：企业级应用、国内用户为主

**配置参数**：
```
SecretId: AKIDxxxxxxxx
SecretKey: xxxxxxxxxxxxxxxx
Bucket: your-bucket-1234567890
Region: ap-guangzhou
```

**配置步骤**：
1. 开通腾讯云 COS 服务
2. 创建存储桶（建议公共读）
3. 获取 API 密钥
4. 在编辑器中填入配置

**优点**：国内速度快、与微信生态契合
**缺点**：需要付费

---

### 4. 七牛云 Kodo

**适用场景**：中等流量、需要 CDN 加速

**配置参数**：
```
AccessKey: xxxxxxxxxxxxxxxx
SecretKey: xxxxxxxxxxxxxxxx
Bucket: your-bucket
Domain: https://cdn.yourdomain.com
Region: 华东
```

**配置步骤**：
1. 注册七牛云账号
2. 创建对象存储空间
3. 绑定域名（必须）
4. 获取密钥

**优点**：有免费额度、CDN 加速
**缺点**：必须绑定已备案域名

---

### 5. 公众号图床

**适用场景**：仅用于微信公众号文章

**配置参数**：
```
appID: wxxxxxxxxxxxxxx
appsecret: xxxxxxxxxxxxxxxx
代理域名: your-proxy-domain.com
```

**配置步骤**：
1. 登录微信公众平台
2. 获取 appID 和 appsecret
3. 配置代理域名（用于跨域上传）
4. 在编辑器中填入配置

**优点**：图片直接上传到公众号、无版权问题
**缺点**：仅限公众号使用

## 图床选择建议

### 按使用场景

| 场景 | 推荐图床 | 原因 |
|------|---------|------|
| 个人博客 | GitHub | 免费、稳定 |
| 企业公众号 | 腾讯云 COS | 国内速度快、与微信契合 |
| 技术文章 | 七牛云 | 有免费额度、CDN 加速 |
| 临时分享 | Telegram | 免费、无需配置 |
| 国际化内容 | Cloudflare R2 | 全球 CDN |

### 按预算

| 预算 | 推荐图床 |
|------|---------|
| 免费 | GitHub、Telegram |
| 低预算 | 七牛云（免费额度） |
| 中等预算 | 阿里云 OSS、腾讯云 COS |
| 企业级 | 阿里云 OSS、腾讯云 COS + CDN |

## 图片上传最佳实践

### 图片优化
- **压缩**：上传前压缩图片，建议单张不超过 500KB
- **格式**：照片用 JPEG，图表用 PNG，动图用 GIF
- **尺寸**：宽度不超过 1080px（公众号显示宽度）
- **命名**：使用有意义的文件名，便于管理

### 批量管理
- 建立图片命名规范（如 `2026-07-18-article-name-01.jpg`）
- 定期清理无用图片
- 备份重要图片到本地

### CDN 配置
对于付费图床，建议配置 CDN 加速：
- 设置合理的缓存时间
- 启用图片压缩转换
- 配置 HTTPS（公众号要求）

## 常见问题

### Q: 图片上传后无法显示？
**A**: 检查以下几点：
- 图床配置是否正确（密钥、Bucket 等）
- Bucket 权限是否为公共读
- 域名是否已备案（国内图床）
- 网络连接是否正常

### Q: 图片加载速度慢？
**A**: 优化方案：
- 压缩图片大小
- 使用 CDN 加速
- 选择离用户近的服务器区域
- 使用 WebP 格式（如支持）

### Q: 免费额度用完了？
**A**: 解决方案：
- 升级到付费套餐
- 更换图床服务
- 减少图片使用，优化图片大小
- 使用多个图床分散负载
